# 新环境入场

在陌生环境里先找到“米”，再谈做什么菜。帮助用户把“我没有方向”“我要证明自己”拆成可以下一周去做的事。方法提炼自Liyuk公开的价值链地图、新人咨询、导师与90天计划、产品概览文章；任务化规则待本人校准。

## 先判断缺的是什么

“需要一个亮点”“想换个方向”是结果诉求，不是可执行问题。先拆：现在的工作是什么，谁分配事情，谁能判断价值，手里有哪些业务信息，能影响哪些人。再判断缺的是方向、信息、授权，还是组织支持。信息和上下文还没有时，不急着在几个方向里选一个；不足的信息不能推出能力不足。

不同上级给出不同期待（例如一方要保交付，一方要能汇报的事）时，先识别为工作条件冲突，双方都可能合理，缺的是一次把目标和边界说清的沟通；不判定谁错，也不替用户编组织关系或谁会支持。

## 画一页价值链地图

从任务而不是功能开始：哪些人来完成什么任务，从输入到结果经历哪些步骤，谁提供输入、谁消费输出、失败后谁处理。至少补齐五类信息：使用者与协作者；他们的任务与成功标准；关键输入、输出和上下游依赖；限制、风险与人工兜底；用什么证据判断变好或变坏。

标出空白比填满更重要：规则谁定的，指标口径是什么，为什么需要人工审批。地图用于提问，不用于假装全知；通常先访谈或观察使用者，再看流程、数据，最后进入代码细节，但顺序可按证据调整。

## 安排信息获取和汇报顺序

为每次沟通写清要获得什么：对方的目标与指标、历史尝试、当前卡点、资源归属，以及对方是否有立场、愿不愿继续提供信息。开场说明自己的背景和刚进入的范围，想法讲成待验证的思路；不假装已懂，也不先抛方案。同时自己补基础，不把所有上下文都要求别人一次讲完。

先汇报，再要资源：带着事实、各方反馈、初步思路和待验证问题做小范围汇报，让决定时间投入的人判断优先级。还没有事实时直接要时间和权限，容易被听成在给自己找额外工作。按组织边界走：谁提供业务立场、谁帮忙连接、谁决定投入，以用户材料为准；未确认的关系标待确认，不建议越级。

## 新人与带教的90天节奏

用户是新人或带新人时，按阶段写四件事：结果（阶段末能独立完成或说明什么）、练习（哪类真实工作）、支持（谁在什么节点帮助）、证据（用什么产出确认进步）。常见节奏：第一个月建立上下文并完成一个范围清晰的小任务；第二个月负责一个含取舍的独立闭环；第三个月主动识别风险、比较路径并留下可复用沉淀。90天不是日历机械切分，按岗位、经验与支持调整。

可以逐步放权的信号：主动澄清目标和完成标准，提出不止一条可比较路径，及时暴露风险并说明所需支持，完成后提炼经验，知道什么问题找谁。阶段反馈描述行为与影响，不把一次结果扩大成人格判断。

## 写入门概览

先写读者看完要作什么判断，用这句话删材料。骨架用用户任务而不是功能清单：用户与情境 → 待完成任务 → 体验机制 → 价值交换 → 关键风险。每条关键陈述标事实、推断或问题；公开页面能支持“对方怎样描述产品”，不能证明规模、留存或动机。竞争写成同一任务的替代路径，不做名单墙。留下范围声明、来源与访问日期、假设清单和更新触发条件。

## 输出

通常给：当前缺口判断 → 一页地图草稿与空白 → 下一周要找谁、各获得什么 → 汇报或下一步。只需要日程、概览或90天计划时直接给对应部分。不替用户选择职业方向；涉及公司内部资料先确认可用范围。选具体任务的指导与授权方式接situational-leadership，与主管对齐预期接one-on-one，谈话措辞接conversation-preparation。
