# 1-on-1：先明确目标，再找支持缺口

归属：原文章支持双方预期、支持、信息与授权的分离。2026-10-14作者进一步确认诊断顺序：目标可共同验收 → 所需能力与个人缺口 → 无法调度的资源 → 授权与跨层协调。下面的记录格式与分支表是任务化整理。

## 先把“做不到”拆开

先理解成员是在寻求目标澄清、方法、资源还是授权，不把请求直接解释为能力不足。一个任务可能同时有多种缺口；顺序帮助识别，不是给人分类。

### 1. 目标能否公开、共同验收

作者所说的量化包括数值指标与产出标准。例如“输出文档”仍不够清楚，需说明文档用于什么决定、需覆盖哪些问题、谁按什么标准认可。多人共同认可的质量标准也可形成验收，不能只接受数字。

“公开”指让相关参与者知道标准并能够讨论，不指必须把公司资料发布到互联网。不能量化／明确验收时，先澄清目标；把不清楚的目标直接交给成员，不适合继续判断其完成能力。

### 2. 所需能力是什么，缺口在哪里

先看任务需要哪些判断和动作，再与成员实际经验对照。没做过、不了解方法、无法作关键判断、执行遇到阻力，不是同一种情况。询问卡在哪一步，已有尝试说明什么，可通过何种工作产物理解缺口。

作者承认能力判断有主观性，应联系具体能力模型与任务，不凭一句“做不到”或一次结果给人定级。给路径、参照物、反馈或指导是负责人提供支持的一部分。

### 3. 哪些资源不能由成员调度

确认完成任务需要的人员、时间窗口、工具、信息或外部配合是否存在，以及成员是否有途径获得。资源存在但成员无法调度也是缺口，不只是资源总量少。列清需要什么、为什么影响目标、谁能提供；未承诺的资源保留待确认。

### 4. 授权与跨层协调是否缺失

确认建议权、决定权、执行权和获得必要信息的范围。资源与权限可能重叠，先把具体事项说清，避免在抽象标签上争论。若需要更高层对话、跨团队优先级或授权，作者的方法是负责人必须介入相应边界，而不是让成员靠个人说服承担未获授权的责任。

## 谁继续负责

| 当前缺口 | 支持方式 | 责任状态 |
| --- | --- | --- |
| 验收不清 | 双方明确结果与标准 | 目标未明确前不作完成承诺 |
| 能力路径不清 | 联系任务能力，给路径、参照与反馈 | 能继续承担的部分由成员推进 |
| 资源不能调度 | 负责人协助取得资源或谈调整范围 | 纯资源问题可以仍由成员负责 |
| 授权或跨层沟通不足 | 负责人介入，必要时向更高层求支持 | 介入不等于自动接管所有实施 |
| 多种缺口并存 | 先解开会阻止后续动作的条件 | 支持未落实的任务不能写成已可完成 |

负责人还需掌握核心项目的一线进度和必要参与，不能只凭汇报表判断问题。这里不规定会议频率或介入比例；具体组织条件仍需实际确认。

## 收尾

记录共同确认的目标／标准、成员继续负责范围、负责人介入事项、资源和权限状态、复看依据。不能提供某种支持就如实说明，再选择缩小范围、延期或等待决定，而不是空头授权。
