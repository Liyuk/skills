# 管理管理者：场景追问与记录模板

归属：二线的必要性与反向检查、通过负责人带人、最小授权流程、结果与代价并看、负责人画像、负责人供给与四角色分工、留与补、交接三件事、治理底线与事故顺序、增人/减目标/改方案，来自Liyuk公开文章。分支表和模板字段是任务化整理，待真实使用校准。

## 现象与先问的事

| 看见的现象 | 先确认什么 | 可能真正缺少 |
| --- | --- | --- |
| 每个团队都在要资源 | 这轮最重要的结果是什么 | 整体优先级与取舍责任 |
| 专项反复卡在交接处 | 谁对范围、协作责任和对外承诺负责 | 统一协作责任与升级边界 |
| 同类冲突总要临时协调 | 这次选择里谁承担代价 | 有授权的结果责任人 |
| 负责人总在替团队扛最后责任 | 哪些决定本应团队自己作 | 团队内责任与升级条件 |
| 负责人总把冲突交给上级 | 权限不足，还是没准备选项 | 补授权，或要求带方案再升级 |
| 团队反复返工 | 目标、协作责任还是验收标准没说清 | 由负责人带回团队落实的边界 |

## 一次取舍之后

| 留下什么 | 为什么 |
| --- | --- |
| 选了什么、暂时放弃什么 | 让协作者知道组织不是什么都要 |
| 谁对结果和对外说明负责 | 决定落地后有主人 |
| 哪些条件出现时重开 | 防止一次取舍变成永久规则 |
| 哪些边界需要同步 | 相关团队知道能决定什么、要配合什么 |
| 让步团队的复评或补偿 | 代价被看见，不变成长期默认 |

## 事后检查顺序

1. 主目标：这轮最想改变的结果发生了吗？主证据由当时目标决定（业务结果、风险控制或合作重建）。
2. 护栏：有没有透支团队、制造单点依赖或损坏协作？
3. 目标与授权：目标、边界、资源和授权里，哪一项让结果偏离？
4. 下一步：保留、改变还是停止什么，什么新信号出现时重开。

## 招聘计划要写清

组织问题；责任范围（负责与不负责）；为什么现在而不是延后、拆分或培养；判断候选人处理过相近复杂度的证据标准；薪酬、编制、地点、支持与授权是否真实存在；目标人才是否存在、评估时间是否够；候选人会知道的真实职责与时间安排；招不到时缩小目标、调整岗位还是改变计划。

| 角色 | 主要判断 | 不替别人决定 |
| --- | --- | --- |
| 二线 | 多团队目标、组织边界、岗位优先级、长期负责人能力 | 候选人全部专业细节 |
| 一线用人负责人 | 岗位真实工作、专业判断、入职后反馈 | 不把模糊需求整体交给HRBP或TA |
| HRBP | 按组织授权参与人员策略、组织设计、员工关系与风险 | 不替业务定义岗位问题，无授权时不替任何一方定性 |
| TA | 招聘策略、人才市场、渠道、流程与候选人体验 | 不替用人团队判断能否承担专业责任 |

各组织对这些角色的授权不同，表格只作讨论起点。

## 负责人选拔时的追问

| 场景 | 值得听的证据 | 容易误判的表象 |
| --- | --- | --- |
| 目标冲突 | 把两个团队目标放回同一结果，说明取舍和代价 | 说话强势，让别人服从 |
| 资源竞争 | 能争取资源，也能说明组织为什么这样分配 | 只替自己团队抢人 |
| 组织变化 | 把模糊变化变成可执行的责任与协作边界 | 会讲愿景，没人知道下一步 |

追问：当时谁有最终决定权，哪项资源没拿到，谁承担了代价，结果没发生准备怎样重来。这不是打分表。

## 人员变化时的检查

哪段目标会立刻没人承接；哪些背景、关系和决定只在一个人脑中；谁能先处理正在发生的风险，还需要什么授权；这个缺口该招聘、内部调整、培养，还是重设目标。

## 管理事故的最小动作

止损与保护（例如暂时调整受影响者的安排，涉事者在结论前不再单独决定其工作分配）；保全事实（排期、记录先留存）；调查角色不向涉事者汇报；结论分层同步（受影响者知道后续安排，涉事者知道边界，其他人知道类似情况往哪报告）；留档；检查排期方式、团队规模、激励与报喜文化等组织条件。正式调查与法律程序优先于本列表。

## 何时停止

有权的人已获得足以决定的选项与代价时，交付决定请求；已决定时转向记录与复评。涉及具体人事处理、法律或政策判断时，指出需由相应专业角色处理，不继续替其下结论。
