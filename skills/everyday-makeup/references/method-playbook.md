# 日常妆容：按目标选择路径

归属：自然光下明度、冷暖、饱和与对比三维度，按当天肤感选质地，产品任务分开，八步上妆顺序，试色记录与购买前清单，来自Liyuk公开的个人学习笔记。来源注明偏自然妆感与偏干皮的持妆思路。下面的精简路径与问题对照为任务化整理，待真实使用校准。

## 按目标选择路径

| 目标 | 保留的步骤 | 可删减 |
| --- | --- | --- |
| 10分钟通勤 | 保湿 → 局部遮瑕 → 薄底妆或只局部底妆 → 眉 → 唇或腮红一色两用 | 鼻影、多层眼影、珠光高光 |
| 久带妆（全天） | 薄铺底妆 → 易出油处局部定妆 → 稳定的眉和唇 | 大面积叠粉、厚遮瑕 |
| 拍照或重要场合 | 完整八步，注意修容与高光的自然过渡 | 按当天肤况删掉堆积的步骤 |
| 练习新手法 | 一次只改一个变量，并记录 | 同时换多款新品 |

## 常见问题对照

| 观察 | 可能原因 | 先试什么 |
| --- | --- | --- |
| 粉底显白、脸和脖子断层 | 明度偏浅或只在手背试色 | 在下颌到颈部试两三个相近色，局部提亮代替全脸选浅 |
| 几小时后变暗变黄 | 氧化或和防晒冲突 | 记录不同时间点的颜色，换搭配再试 |
| 眼下积线 | 遮瑕过厚或过亮 | 缩小范围、减少用量、薄定妆 |
| 腮红显脏或突兀 | 明度或饱和度不协调 | 降低用量、晕开边缘，或换明度相近的颜色 |
| 修容像脏印 | 颜色发红发橘或过亮，边界明显 | 选更接近自然阴影的颜色，从后往前少量扫 |

## 八步的关键动作

1. 妆前：修眉；全脸薄涂保湿；局部用校色产品中和唇周、嘴角等暗沉。
2. 遮瑕：先液体遮瑕处理黑眼圈最深处，“点、拍、过渡”，目标是中和而不是提亮过度。
3. 粉底：扁平刷上脸，湿粉扑垂直拍开，避开重点遮瑕区；可用定妆喷雾成膜后再补小瑕疵。
4. 提亮与塑形：少量提亮凹陷处；液体修容点在颧骨侧后方与下颌线；高光区不叠修容。
5. 定妆：以按压代替扫开，先定易移动区域。
6. 修容与鼻影：侧面略深、正面清爽、没有明显边界。
7. 眼妆：浅色打底、逐层加深，最深色贴近睫毛根部；眼尾平稳不下垂。
8. 收尾：腮红、少量珠光高光、顺着毛流补眉、唇色与腮红眼影色调相近。

距离与次数等细节因人和产品而异，只作练习参考。

## 何时停止

用户已经知道下次要试的一两个调整时，不再展开。出现不适、疑似皮肤问题时停止产品建议，建议咨询专业人士。
