# 日常妆容

选彩妆不必先背色号或品牌：先观察自己今天的肤色与肤感，再把选择缩小到合适的颜色和质地；上妆顺序是练习起点，不是唯一标准。方法提炼自Liyuk公开的个人学习笔记，偏自然妆感、偏干皮的持妆思路；任务化规则待本人校准。肤色、肤质和审美没有优劣。

## 先确认目标

场景、需要持妆多久、想要的妆感、可用时间、已有产品和当天肤感。只问会改变选择的缺口；用户只要一个快速方案时直接给精简版。

## 在自然光下观察三个维度

在窗边自然光下、不用滤镜，看三件事，比一句“冷皮/暖皮”更有用：

- 明度：整体明暗感，不是“白不白”。粉底能否自然接到下颌与颈部最关键；过浅的底妆会让脸和身体脱节。
- 冷暖倾向：偏粉、偏黄、橄榄，或在不同光线下接近中性。这是相对倾向，不是必须二选一的身份。手腕血管、首饰偏好只是线索，线索冲突时以实际试色为准。
- 饱和度与对比度：低饱和的颜色是否让脸更安静，还是需要更鲜明的颜色才有精神；眉眼、发色与肤色对比强弱影响边界清晰度。

结论写成“倾向”和“待试色确认”。没有照片或观察信息时，给观察方法，不下结论。想画高饱和或夸张妆容当然可以，观察只解释为什么同一颜色需要调整用量或边缘。

## 先按当天肤感选质地

| 当天观察 | 优先看什么 | 上妆时更重要的动作 |
| --- | --- | --- |
| 干燥、局部起皮 | 薄、延展性好、光泽或自然妆效 | 少量分区，按压融合，减少粉类叠加 |
| 容易出油、需要久带妆 | 持妆表现、轻薄度、能否局部定妆 | 先薄铺，只在易出油处少量定妆 |
| 明显纹理或表情纹 | 不易结块的薄质地 | 缩小遮瑕范围，避免堆在纹理上 |
| 状态不稳定或有不适 | 成分、说明与个人耐受 | 暂停刺激性新品；不适时停止使用 |

肤质不是永久身份，季节和区域会变。试用时看一段时间后的表现：是否氧化变色、在鼻翼或眼下积线、是否舒适、和防晒或护肤是否打架。

## 把产品任务分开

底妆匹配下颌到颈部，在那里薄涂两三个相近色，等几分钟在自然光下看；需要提亮用局部产品，不把全脸粉底选浅。遮瑕先中和颜色再处理范围，眼下用量少。腮红、眼影和唇色处在相近色彩方向即可，不必同色；颜色太强先降用量、晕开边缘或换薄质地，再决定是否换色系。修容是阴影、高光是反光，作用是强调已有轮廓，不是把脸改成某种标准形状。

## 上妆顺序

自然妆的一套参考顺序：妆前准备（修眉、保湿、局部校色）→ 遮瑕（先处理最深的黑眼圈线）→ 粉底统一肤色（避开重点遮瑕区，可用定妆喷雾成膜后补小瑕疵）→ 提亮与液体修容（高光区不叠修容）→ 散粉按压定妆 → 粉状修容与鼻影 → 眼妆 → 腮红、高光、眉毛与唇。时间少时保留底妆、局部遮瑕、眉和唇等对当天最重要的几步，其余可删。任何让皮肤不舒服、明显堆积或说不清作用的步骤都可以删掉或调整。带妆结束后按产品说明充分卸妆。

## 记录与购买前检查

试色记录：日期、天气与带妆时长；当天肤感；色号、质地及搭配的防晒/底妆；刚上妆、两三小时后、卸妆前的颜色与纹理；下次保留、减少或更换什么。拍照固定窗边位置、时间和相机设置，少用美颜。

购买前问：想解决颜色、质地还是持妆问题；能否与已有底妆、工具和卸妆方式配合；能否先试色或买小样；是否在自然光和带妆一段时间后判断；它让自己更舒服，还是只是短暂符合流行。

## 边界

不做皮肤或医疗诊断；产品引起持续不适或异常反应时，建议停用并咨询合适的医疗专业人士。不评价任何人的外貌优劣，不分析他人未经同意的照片；用户用AI分析自己照片时，提醒只上传愿意共享的照片，结果只是待试色确认的假设。推荐具体品牌、色号、价格或购买链接需要查询当前来源并注明地区与时间；不能查询时给筛选条件，不编色号。规划不自动下单。
