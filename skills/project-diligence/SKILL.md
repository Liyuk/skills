# 项目判断

同样是“看一个项目”，目的不同，问题就不同：画布是做给自己看（这生意成立吗），路演是讲给别人听（为什么值得投），尽调是别人来查（到底值不值、值多少）。先说清用户站在哪个视角，再用对应口径判断。方法提炼自Liyuk公开的学习笔记与复盘文章；商业模式画布等是外部公开框架。任务化规则待本人校准。

## 先说清视角和阶段

问用户：是自己判断要不要做、准备对外讲，还是要核验别人给的项目？处在想法、验证、扩张还是成熟阶段？三种视角部分重叠，不是流水线：画布填满不等于能投，路演讲通不等于经得起查。

## 用画布查自洽

九格：客户细分、价值主张、渠道通路、客户关系、收入来源、核心资源、关键业务、重要伙伴、成本结构。用处不在填满，而在查格与格之间能否互相解释：选的客户会不会被价值主张打动；收入能否长期盖过成本；关键业务和核心资源是否在撑价值主张。薄不等于缺，有些格子本就该轻。

按阶段找当前必须回答清楚的问题：

| 阶段 | 必须回答 | 判断 |
| --- | --- | --- |
| 想法 | 客户细分 + 价值主张 | 那群人是否真有那个痛，能否低成本实验检验 |
| 验证 | 价值主张 + 渠道 + 收入雏形 | 有没有人愿意付钱，而不只是说好 |
| 扩张 | 关键业务 + 核心资源 + 成本结构 | 放大时会不会亏，供给与履约撑不撑得住 |
| 成熟 | 客户关系 + 收入来源 + 成本结构 | 复购、留存、毛利与护城河还在不在 |

还没验证的格子可以先作为假设，但要按假设管理；最致命的不是格子空着，而是把假设讲成事实。

## 看清供需

谁在使用，谁付钱，谁提供产品或服务，双方怎样接上，钱最后落到谁手里。用户说想要不等于愿意付费；有人付费也不代表供给方能以合理成本持续提供。还要问：眼下钱在哪一层，供给扩上来、替代方案变多后，这个优势能维持多久。市场规模只是其中一项。

## 尽调：独立验证与重新定价

按阶段调整权重核验：人和团队；行业空间、增速、竞争、政策与周期；商业模式的单位经济与护城河；规模与增长；利润与现金流；资产与负债；壁垒；法律、税务与合规；估值与退出。早期更看人与问题，成长期看增长、单位经济与可复制性，成熟期财务权重最大；每个阶段用不同证据看同一件事：生意能否持续赚钱。

尽调的本职是独立验证承诺的成色，多数结论是“没造假，但值不了那个价”。数据之间对不上时，标为需要核验的红旗，不采信也不直接下造假结论。

## 进入、继续与退出

投入前写计划：投入什么、多少，阶段目标，继续、转向或退出的条件，能承受的损失。已经投入时，回到预设条件判断；没有预设就先补上，避免沉没成本带着走。继续观察前问清在等什么信息：等来的信息会改变决定，等待才可能值得；同时记下等待的代价。

把现状（已发生的付费、交付、数据）、推演（需求会不会扩大）和愿望（希望成功）分开写；愿望不能当作市场会照此发展的证据。复盘看依据和动作，如果复盘不改变下一次做法，记录再多也没用。

## 输出

通常给：当前视角与阶段 → 必须回答清楚的问题及证据状态 → 供需与单位经济的关键缺口 → 进入/继续/退出条件或下一步验证。需要当前市场、财务或公司数据时查当前来源并注明日期；无法查询就列为待核验，不编数字。

法律、税务与审计问题交给相应专业人士，这里不下结论。数字口径和可比性本身是否可信，用 `metric-decision`。公开公司案例只用已公开信息。
