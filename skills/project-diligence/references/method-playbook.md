# 项目判断：清单、原型与分支

归属：画布/路演/尽调三视角、画布格间咬合检查、按阶段的主矛盾表、“把假设讲成事实”、尽调重点与阶段权重、供需两侧看法、入场出场与等待的信息价值、现状/推演/愿望分开，来自Liyuk公开文章。商业模式画布、精益画布、价值主张画布归原作者；路演十页结构在来源中注明是公开推荐结构的合成。分支表为任务化整理，待真实使用校准。

## 三视角对照

| 维度 | 画布 | 路演 | 尽调 |
| --- | --- | --- | --- |
| 目的 | 讲清生意怎么运转 | 说服为什么值得投 | 验证值不值、值多少 |
| 谁在看 | 创业者自己 | 创业者对投资人 | 投资人对项目 |
| 口径 | 事实与假设 | 承诺与亮点 | 独立验证与重新定价 |
| 时间感 | 快照 | 现在与未来 | 历史、现在与未来 |

## 路演检查

常见结构：问题 → 方案 → 市场 → 为什么现在 → 产品 → 商业模式 → 竞争 → 团队 → 牵引力 → 融资请求。用户准备路演时，帮助每页说清承诺；用户在听别人路演时，把每页的承诺改写成尽调要核验的问题，例如市场规模的口径、牵引力的数据来源。

## 原型帮助找关键咬合

| 原型 | 咬得最紧的格子 |
| --- | --- |
| 多边平台 | 多边客户细分 × 匹配撮合 |
| 剃刀+刀片 | 规格锁定的客户关系 × 耗材复购收入 |
| 免费增值 | 成本结构 × 付费转化 |
| 注意力平台 | 推荐等价值主张 × 广告收入 |
| 高频带低频 | 高频刚需养用户 × 低频高毛利变现 |

认出原型，就知道先盯哪几格。原型只帮助提问，不证明模式成立。

## 尽调核验清单

- 收入真实性：订单、流水、税务与发票和系统数据是否一致。
- 单位经济：单店或单客的收入、成本与补贴，是真盈利还是补贴堆出来的。
- 成本与供应链：采购真实性、关联方交易。
- 现金流：消耗速度、余额、融资依赖。
- 治理：股权结构、关联交易、审计意见。
- 合规：许可、用工、数据与反垄断等红旗。

## 按情境选择入口

| 用户情境 | 先做什么 |
| --- | --- |
| 自己想做一个项目 | 定阶段，找必须回答的问题，设计低成本验证 |
| 准备对外讲 | 每页承诺对应可给出的证据，假设明说是假设 |
| 核验别人的项目 | 把承诺改写成核验问题，按阶段排权重 |
| 已投入一段时间 | 回到预设阶段目标与退出条件；没有就先补 |
| 只有市场规模和愿景 | 回到供需：谁付钱、供给能否持续 |
