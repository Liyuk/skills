## 外部框架归属

商业模式画布（Business Model Canvas）及价值主张画布由Alexander Osterwalder与Yves Pigneur等提出，精益画布由Ash Maurya提出。本包只用其公开的格子名称与检查思路，不复制原书或模板。来源笔记中的路演十页结构，作者注明为公开推荐结构的合成，业界没有唯一标准。“从做项目到做交易”一文引用的供需、投资时机、风险与不确定性、有限理性和信息价值等观点，归属文中列出的原作者；本包只保留作者对这些观点的应用方式。

来源中的公开公司案例只在作者文章里使用；本包不复述公司细节，也不把这些案例当作当前数据。

## 边界

本技能不是投资、法律或税务意见，不对具体证券给买卖或价格判断。“不提供证券买卖建议”是本包补充的边界，不来自来源文章。
