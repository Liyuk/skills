# 决策汇报结构参考

这是按需选用的结构，不是每份材料都要填满的模板。先确认读者要作什么决定，再保留与该决定相关的部分。

1. **决定请求**：要决定什么、谁决定、最晚何时需要决定；未知时标注待确认。
2. **现状与依据**：目标、范围、基线和关键证据，注明来源、口径、时间窗口与证据状态。
3. **判断与选项**：当前问题、可选路径、收益、成本、风险和机会成本；没有充分证据的部分作为假设。
4. **建议与条件**：建议的选项及适用条件，什么证据或变化会使建议失效。
5. **执行与护栏**：责任、依赖、里程碑、验收、观测、回退和复查时间；未知字段保留为待确认及补齐方法。

如果用户只要一段摘要，可压缩为：结论/决定 → 依据 → 主要风险或未知 → 下一步/需要的支持。不要为了“像汇报”而补造竞品数字、成本收益或成功率。
