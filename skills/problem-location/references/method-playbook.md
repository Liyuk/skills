# 问题定位：工具归位与场景分支

归属：四阶段主线（结构化→发觉联系→推论底层问题→找到解决方案）、五镜、换方案测试、四格命题、Top K、“数数”复述与好问题三要件来自Liyuk公开文章。下面的分支表与停止条件是任务化整理，待真实使用校准。

## 每个工具服务哪一步

| 阶段 | 工具 | 解决什么 | 常见误用 |
| --- | --- | --- | --- |
| 结构化 | 结论先行、四格命题 | 让别人能指出不同意的是哪一格 | 只套形状，不补证据 |
| 结构化 | 不重不漏的拆解 + 假设排序 | 拆得全，再决定先查哪块 | 拆全了却平均用力 |
| 结构化 | 归纳与演绎 | 区分必然结论与或然概括 | 两次结果当规律 |
| 结构化 | 5W2H、先问为什么 | 检查问题陈述有没有缺维 | 变成冗长清单冲淡主线 |
| 联系 | 多层追问、鱼骨图 | 追因果链 | 相关、先后当因果 |
| 联系 | 两维正交切四格 | 把模糊排序逼出判断 | 强行二分 |
| 底层 | 断言—数据—依据—限定—反驳 | 找出论证塌在哪一件 | 只当修辞 |
| 方案 | 决策矩阵、取舍 | 把隐含标准摆出来，明说放弃了什么 | 把主观权重当客观分数 |
| 方案 | 可验证目标、停止条件 | 落成可检查的行动 | 可衡量却不对准底层 |

不需要一次用完。一段真实材料走一遍“结构化→联系→底层→对准”的小闭环通常够用。

## 按材料状态选择入口

| 当前材料 | 先做什么 | 停在哪里 |
| --- | --- | --- |
| 一句情绪化抱怨 | 复述可能的一到三个问题，让用户选重点 | 用户确认要解决的问题 |
| 有现象、没有事实 | 列需要的最小事实（如一周请求记录）和谁能提供 | 调查计划，不下根因 |
| 有事实，双方各执一词 | 事实表并排；二元、辩证、立场三镜 | 指出争议在事实、目的还是规则 |
| 有事实，方案反复失效 | 换方案测试，找同时解释多个症状的约束 | 可反驳的底层陈述 |
| 有多个候选方案 | 对准检查、取舍、停止条件 | 推荐及放弃项 |
| 一长串待办或问题 | 先定口径，再排前K | 排序与不做清单 |

## 人的两镜怎样用才不越界

立场镜问“在这个位置上想达成什么、怕失去什么”，利益镜问“谁承担代价、谁获益、真正原因是什么”。两者都只基于材料中的陈述、角色和可观察行为。写法用“从材料看，A要保护上线日期”，不写“A故意拖延”。缺席方的目的列为待问问题。

利益分析发现某方从现状获益，不等于该方有意制造问题；原则、惯性、误解同样可能。若用户要求“证明对方在算计”，先说明利益镜不能证明主观意图，再列可核对的行为和下一步；出现具体胁迫、欺骗或报复线索时转风险处理。

## 好问题的三项检查

具体：对象、场景和时间范围清楚。可判断：存在证据、反例或可比较的标准。可行动：回答后能导向一次验证、一次取舍或一个下一步。三项不满足时，继续补事实、缩边界，不急着找答案。

比较与因果是两条主要追问线：现在与预期差在哪里、好坏案例差在哪里；哪个环节是根因，改变它后面的结果是否随之改变。

## 何时停止

底层陈述已经可反驳、方案已经对准、下一步调查已有负责人可执行时，停止分析，转入执行。数据充足、需要统计或实验判断时，交给指标与实验方法；需要多方决定权时，交给冲突对齐。五镜不声称完备，用不上某一镜时直接略过。
