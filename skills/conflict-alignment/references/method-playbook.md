# 冲突对齐：按分歧类型选择下一步

归属：共同目标、事实、决策权与选择记录来自原文章；“同层无让步空间时停止重复协调并上升支持”由作者在2026-10-14明确补充。下面的分支表与交付字段是任务化整理，仍待真实使用验证。

## 先识别卡在哪里

不要把双方使用同一句目标当成目标一致。按当前材料判断分歧，不要求全部检查。

| 观察 | 先处理什么 | 可得到的产物 |
| --- | --- | --- |
| 对结果定义不同，例如一方要保日期、一方要保完整范围 | 把必须结果与可协商项分开，确认各自目的与代价 | 共同结果或明确的不一致 |
| 对改动、容量、依赖有不同说法 | 并排保留版本，找能核验的文档、任务或观测 | 事实表、核验动作 |
| 接受同样事实，但对成本、收益或风险容忍不同 | 比较有实质差异的路径，找谁承担哪类代价 | 选择及其受影响者 |
| 各有领域决定权，整体取舍没人能决定 | 明确跨边界决策缺口，寻求相应层级支持 | 决策请求 |
| 同层无法调整各自目标、资源或承诺，反复沟通仍无空间 | 停止重复辩论，整理材料，向更高层寻求支持 | 升级材料，不是指责材料 |

只缺一项可验证信息，且验证能改变选项时，可提出小范围验证；它不是所有冲突的默认答案。事实已经明确、硬约束不相容时，再加会议或试验可能没有作用。

## 作者确认：什么时候上升

确认双方已经能说明目标、事实及决定边界，但各自压力和约束使其不能让步，当前层级也无法调度足够支持。此时先停止无新增信息的沟通，将问题从“谁配合谁”转成“需要上层决定哪项取舍、提供哪种资源”。

整理必要信息：共同结果与不同诉求、各自不能改变的约束、已比较的选择、影响与风险、当前层级为何无法解决、所需资源／权限及具体决定请求。不要只汇报“沟通失败”。

升级不是把全部事实和执行责任甩出去。能够完成的准备和执行仍可由原协作方承担；更高层负责其权限范围内的取舍与资源安排。上层未决定前，不能写成已批准变更。上层也没有相应权限时，指出还缺谁的决定，不无限猜组织层级。

## 选择记录的最小信息

根据决定的重要性记录：要改变的结果；事实与仍有分歧的依据；选项及各方代价；已确认决定或待决项；需要谁的权限；下一步核验；什么信号重开决定。日期与负责人只有确认后才列为承诺。

若最终约束仍无法兼容，可以报告暂不能承诺该协作方案，并说明是哪项结果或边界没有被授权改变。停止合作的条件尚未获得作者进一步校准，不作为默认升级结果。

## 何时停止分析

信息足够让有权的人作决定时，交付决定请求；已有明确决定时，转向执行边界和复看。用户只要短评时压缩到卡点、依据与下一步，不将表格变成固定格式。
