# 参考说明

## 能力模型

本 Skill 会把原始素材重组得更清楚，重点围绕四个维度展开。只使用材料里已经有的内容；某个维度没有证据时写成待确认，不要为了显得完整而升级角色、影响或长期价值：

1. **结果**
   - 最终做成了什么
   - 哪个结果最值得被记住
   - 哪个变化最值得被汇报

2. **影响**
   - 为什么这个结果重要
   - 对业务、团队或组织产生了什么价值
   - 谁因此受益，或减少了什么损失

3. **复杂度**
   - 这个问题为什么难
   - 是否存在目标冲突、信息不充分、资源有限或跨团队协同难题
   - 是否需要做关键判断与取舍

4. **成长与杠杆**
   - 是否沉淀了可复用的方法、机制或模板
   - 是否创造了长期价值，而非一次性价值
   - 体现了什么更高层级能力

## 常见改写方式

改写只重组材料里已经有的事实、范围和未知。下面每组都先给出素材里有的内容；“可用”只把这些内容说清楚，“不可用”则补了材料没有的角色、收益或机制。

### 1. 从动作改写为结果

素材：协调搜索、算法、平台三个团队的联调；第二周卡住的特征接口在周五恢复联调。

可用：推动搜索、算法、平台三方把卡住的特征接口在第二周周五恢复联调。

不可用：对齐多个团队节奏，推动关键里程碑全面恢复，并显著提升交付效率。材料没有“全面”，也没有效率数据。

### 2. 从结果改写为影响

素材：上线方案已完成；尚未有协同成本或复用数据。

可用：上线方案已完成。协同成本是否下降、是否形成可复用模板，材料里还没有证据。

不可用：完成上线方案的同时降低了协同成本，并沉淀出可复用模板。

### 3. 从参与改写为范围与 owner 角色

素材：上级要求评估搜索排序；本人协调评估方案并推动接入；模型由算法团队负责，特征服务由平台团队提供。

可用：在评估搜索排序的任务里，协调评估方案和接入；模型与特征服务分别由算法团队和平台团队负责。

不可用：主导了全链路搜索智能化改造。

### 4. 从执行改写为晋升叙事

素材：在资源有限、目标最初不清楚的情况下交付了项目；没有组织级收益数据。

可用：在目标最初不清楚、资源有限的条件下完成了该项目交付。组织级或长期机制收益尚未被材料证明。

不可用：形成超出单项目价值的组织收益。

## 输出类型选择建议

### 适合用“管理汇报版”的情况
- 面向老板或管理链路
- 需要快速扫读
- 关注当前进展、风险和下一步

### 适合用“项目总结版”的情况
- 需要沉淀一个项目的完整过程和结果
- 过程、结果和经验教训都重要

### 适合用“高管摘要版”的情况
- 需要极致压缩
- 阅读时间非常短
- 重点是帮助快速判断

### 适合用“晋升 / 自评版”的情况
- 用于绩效、校准、述职、晋升
- 需要强调职责范围、复杂度、影响力和成长
- 需要支撑更高一级能力判断

## 素材不够强时的追问建议

如果原始素材不足，可以补充追问：
- 最重要的可量化结果是什么？
- 这件事最难的地方是什么？
- 影响到了哪些团队、角色或链路？
- 有没有沉淀出机制、模板或方法论？
- 你最希望评审者记住哪一点？
