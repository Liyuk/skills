# 动力下降：先分辨原因，再选支持动作

用于成员在某项任务上明显失去动力、回避新任务或不再提改进，负责人想判断“该给什么”时。它补充情景领导力的“投入”判断，不是新的等级。

归属：原则来自Liyuk公开文章《当一个人失去动力，管理者能做什么》，并参考《人的激励法则：情景激励模型》中描述性的部分（动机质量、去负与增正、阶段差异）。后者是作者标明的未经实验验证的概念模型预印本，本包只借用描述性观点，不把它当作有效性证据，也不作处方。这里与Blanchard的SLII各自独立：不把下面的原因分类写成D1—D4的新定义，也不声称作者认可两者的组合。合成示例和动作清单是AI任务化候选，待本人校准。

## 不要先判成态度问题

“最近是不是不积极”只会让对方自证清白。先描述可观察的事实，再请对方解释：“最近三个任务都按时完成，但很少再提出改进；我想知道是工作安排、目标理解，还是其他因素让你卡住？”谈完只约定一个可观察的下一步，两周后复查，不指望一次谈话解决一切。

先问三件事：他是否知道当前工作解决什么问题；投入与可见的成长、认可或回报之间是否仍有可信联系；负荷是否超过能持续承担的范围。

## 不同原因，不同动作

| 材料支持的原因 | 先做什么 | 不要做什么 |
| --- | --- | --- |
| 方向不清 | 重述目标、优先级和这项任务的意义 | 只喊“要主动” |
| 承诺一再被打断，不再相信会兑现 | 删掉一部分任务、公开优先级、给一段能完成的闭环 | 继续谈“主人翁精神” |
| 角色长期单调 | 提供可选择的挑战和支持 | 把挑战包装成必须接受的机会 |
| 环境不公平或缺少反馈 | 调整机制，补反馈 | 把组织问题归为个人状态 |
| 个人状态困难 | 尊重隐私、给合理弹性与求助渠道 | 诊断心理状态，或要求保持热情 |
| 缺具体能力、尝试后受挫 | 回到任务能力判断，补指导与支持 | 当成违纪或只给鼓励 |

多种原因可能并存。材料只有负责人一方的判断时，成员视角标为待核对，不替成员编原因。

## 边界

不承诺无法控制的晋升；不把组织本该解决的风险转成个人必须燃烧的义务；不强迫成员接受任务；动机不是可以用外部奖励调高的固定属性，外部奖励也可能削弱原有的内在理由，因此加钱、发奖不是默认解法。早期、中期和后期的主要需求可能不同，但这只是解释为什么同一情境对不同人不同，不用于给人贴阶段标签。

能力与权限问题仍按本技能主流程处理：资源不足可由负责人协调、成员继续负责；权限缺口由负责人介入。资源与权限阻塞时，不把进度慢解释为投入低。
