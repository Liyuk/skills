# 情景领导力：把理论变成可观察的分流

用户提出新增情景领导力助手，并追问书籍视角是否提升AI识别能力。沿用先加入自用、再校准的方向，增加独立自动发现的 situational-leadership；已有 one-on-one 继续处理谈话与支持责任，导航按当前目标选择，不要求每次谈话都做理论分类。当前 PR #2 尚未合并，补充仍在同一分支。

以 Blanchard 的 SLII 公开作者／机构资料作为本轮明确版本，不把 Hersey/CLS 的 readiness 编码混入。按具体人、具体任务和当前阶段观察能力，以及本人表达的动机／信心，给出指导与支持的组合；不对整个人贴等级。先有共同验收标准，再排除资源／授权瓶颈。信息缺失或冲突时输出未知、可分辨的问题和临时支持，不硬配四类。

经典框架的作用是提供可区分的维度。本项目补充的是工程任务证据、动作、授权护栏及复看信号，属于候选适配；用户确认过的权限介入分支保持有限归属。输出围绕判据、暂定建议、成员与负责人的动作、何时调整，不生成绩效评分或人格判断。

案例要覆盖新任务／熟悉任务、低能力高投入／受挫学习、会做但不自信／可靠自主、能力与权限分别变化，以及相互矛盾的材料。先观察当前1-on-1的六探针基线，再读取新包重做并记录实际响应；不制造红例，也不将一个代理的前后响应当因果证据。新增案例的 expected_output 均为判定标准。

书籍使用分为：来源可追溯；概念转成判据；相近场景导致不同动作；对照验证提升。本轮争取前三层，第四层保留待验证。目录、客户端元数据、Ask地图、插件清单、README及使用说明一起更新，技能本地链接自包含，随包保留许可。
